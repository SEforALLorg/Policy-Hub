

## Knowledgehub

Knowledgehub is Web front-end server.

[here](https://knowledgehub.seforall.org/) is aplication live URL.


## Runing Locally

Git Repository [here](https://github.com/shivenj/vkh-fe).

Install and Build NPM Packages:
````
$ npm install
$ npm run build
````
Run and Build Packages:
````
$ npm run dev
$ npm run build
````

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `pages/index.js`. The page auto-updates as you edit the file.

API Base URL [https://kmit-vkh.herokuapp.com/api](https://kmit-vkh.herokuapp.com/api).
